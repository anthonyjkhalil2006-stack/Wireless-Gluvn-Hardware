# Anthony: gyro, accelerometer and compass fusion on the ESP32-S3 test rig

This folder holds Anthony's offline analysis of gyro, accelerometer and compass fusion on an ESP32-S3 breadboard rig (MPU-6050 and a QMC5883L clone). `logger.py` saves the 50 Hz serial stream from `firmware/gluvn_logger.ino` to CSV. `analysis/accel_calibration.py` fits a per-axis offset and scale from six-face rests (the z axis has a +1.4 m/s² offset, outside the datasheet's ±80 mg). `analysis/compass_calibration.py` fits an ellipsoid to remove the board's hard- and soft-iron effects. `analysis/tilt_compensation.py` flattens the field and the glove's x axis onto the horizontal plane using the accelerometer's "up". `analysis/gyro_quaternion.py` integrates the bias-corrected gyro into a quaternion and reads yaw, and `analysis/fusion.py` blends that with the compass using a gated complementary filter (α = 0.995). On one tilt test, the heading error fell from 14.0° to 7.5°; the remaining error is not yet explained. All of this is Python run offline, and nothing is ported to the ESP32 firmware yet.
